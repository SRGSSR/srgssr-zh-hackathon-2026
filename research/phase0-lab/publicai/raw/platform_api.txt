 Lists the currently available models 
 GET https://api.publicai.co
 /v1/models
 Returns a list of all available models that can be used with the chat completions endpoint.
 Lists the currently available models › Headers 
 Authorization
 string  ·  required 
 The Authorization
 header is used to authenticate with the API using your API key. Value is of the format Bearer YOUR_KEY_HERE
.
 User-Agent
 string  ·  required 
 User-Agent header identifying the client application
 Lists the currently available models › Responses 
 200 OK
 object
 string  ·  enum  ·  required 
 The object type, which is always 'list'
 Enum values: list 
 data
 object[]  ·  required 
 The list of models
